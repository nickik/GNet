# GNET-A — superseded name

`GNET-A` was the provisional name for the centrally scheduled shared broadband-access profile.

The canonical name is now **[[GNet Broadband Access|GBA]]**, with **GBA10** as the first defined 10 Mbit/s-up / 10 Mbit/s-down shared-access profile.

This note is retained only so historical links continue to resolve.
